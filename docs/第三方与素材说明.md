# 第三方代码与素材说明

## 一、代码依赖

本项目**没有任何 npm 运行时依赖**：`package.json` 中没有 `dependencies` / `devDependencies`，`node_modules` 不存在，也不需要 `npm install`。

用到的全部是 Node.js 内置模块：

| 模块 | 用途 |
|---|---|
| `node:http` / `node:https`(经全局 fetch) | HTTP 服务与 MCP/LLM 调用 |
| `node:fs` / `node:path` / `node:os` / `node:url` | 文件、路径、缓存目录、模块路径 |
| `node:crypto` | 缓存键哈希 |
| `node:child_process` | 仅测试脚本用于拉起无头浏览器 |
| `node:test` / `node:assert` | 测试框架（Node 内置） |
| 全局 `fetch` / `WebSocket` / `AbortSignal` | Node 20+ 内置，无 polyfill |

前端为手写 HTML/CSS/JavaScript，**未引入** React、Vue、Tailwind、ECharts、Chart.js 等任何库；也没有外部 CDN 引用。

## 二、测试与截图

- 浏览器自动化测试通过 Chrome DevTools Protocol 直连本机已安装的 Chrome/Edge，**未**引入 Playwright/Puppeteer 依赖（只 spawn 浏览器进程 + 原生 WebSocket）。
- `docs/screenshots/*.png` 与 `.shots/*.png` 为应用运行截图。本轮复核全部 13 张 PNG，未见凭证、账户或私人路径。截图含品牌/商品名称、红底黄字 M 标识；自行截图不证明品牌元素授权，作者已确认保留当前界面及全部截图公开；该决定不构成第三方品牌授权。
